    Rules & scoring

    A = 1, J = 11, Q = 12, K = 13. Capture any table group with the same total as one or more cards from your hand, or place one card. Clearing the table earns a sweep point. The next player places on the empty table and plays again if they still have cards. When both hands run out, the last capturer receives three new cards first and leads. At the end, the last capturer collects the remaining table cards.

    27+ cards: 3 points · 7+ spades: 2 points · Each ace: 1 point · 10♦: 2 points · 2♠: 1 point · Each sweep: 1 point. Displayed scores count points earned so far; card and spade bonuses appear when their thresholds are reached.
